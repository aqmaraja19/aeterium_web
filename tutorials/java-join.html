TUTORIAL / JAVA EDITION

Cara Bergabung ke Server

Ikuti langkah-langkah berikut untuk mulai bermain di AETERIUM SMP menggunakan Minecraft Java Edition.

Java Edition • Panduan Pemula

Persiapan

Pastikan Minecraft Java Edition sudah terpasang dan perangkatmu memiliki koneksi internet. Gunakan versi Minecraft yang didukung oleh server.

LANGKAH 01

Buka Menu Multiplayer

Jalankan Minecraft Java Edition. Dari menu utama, pilih tombol Multiplayer untuk membuka daftar server.

LANGKAH 02

Tambahkan Server

Klik tombol Add Server. Masukkan nama server, misalnya AETERIUM SMP, pada kolom nama.

LANGKAH 03

Masukkan Alamat Server

Masukkan alamat berikut pada kolom Server Address.

play.aeteriumsmp.my.id:19199
LANGKAH 04

Simpan dan Bergabung

Klik Done, pilih AETERIUM SMP dari daftar server, kemudian klik Join Server.

Jika gagal terhubung, periksa kembali alamat, port, koneksi internet, dan versi Minecraft.

Catatan Penting

Jika muncul pesan kesalahan, catat pesan tersebut agar lebih mudah mencari penyebabnya. Status server dan versi yang didukung juga dapat memengaruhi keberhasilan koneksi.
